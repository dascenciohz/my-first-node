# My First Node JS Project. Feliz.

## Requisitos

- Node.js 26 LTS (ver `.nvmrc`; con nvm: `nvm use`)
- MongoDB accesible (por defecto `mongodb://localhost:27017/statuspage`, configurable con `MONGODB_URI`)

## Uso

```bash
npm install
npm start      # produccion
npm run dev    # recarga automatica con node --watch
```
